# 코드룸

### 가사 자동 추가 · YouTube MP3

- 악보를 열면 LRCLIB에서 가사를 찾습니다. 곡명·가수가 일치하는 결과는 자동 추가하고, 여러 버전은 선택 목록으로 제공합니다.
- 시간 정보가 있는 가사는 재생 타임라인에 연결합니다. 일반 가사는 임시 균등 배치라고 표시하며 직접 타이밍을 조정할 수 있습니다.
- ‘유튜브 음원 · 다운로드’에서 영상 링크를 넣고 MP3를 추출한 뒤 다운로드하거나 코드 분석·가사 연습으로 보낼 수 있습니다.
- **음원 추출은 별도 서버 연결이 필요합니다.** `dist/config.js`에 배포한 서버 URL을 넣거나 웹앱의 서버 연결 설정에서 입력하세요. 서버가 연결되지 않으면 추출할 수 없다고 표시합니다. 설치·배포·제한은 [서버 안내](server/README.md)를 참고하세요.
- LRCLIB에 없는 곡, 정확한 곡 정보가 없는 파일, YouTube에서 다운로드를 제한한 영상은 자동 처리되지 않을 수 있습니다.

이전 구현 안내 아래의 ‘자동 가사 수집 미지원’은 이 업데이트 이전 상태입니다. 현재 LRCLIB 조회는 지원하지만 음성 인식으로 가사를 받아쓰는 기능은 없습니다.

[웹앱 실행](https://wonderer1004-maker.github.io/chordroom/) · [소스 저장소](https://github.com/wonderer1004-maker/chordroom)

GitHub Pages는 `main` 브랜치의 루트(`/`)에서 게시합니다. 루트 `index.html`은 실제 앱이 있는 `dist/`로 이동합니다. 별도 설치나 빌드가 필요하지 않습니다. 로컬 미리보기는 저장소 폴더에서 `node preview.cjs`를 실행한 뒤 `http://127.0.0.1:4173`을 엽니다.

2026-10-28 업데이트: 악보 재생/일시정지/정지/탐색, 0.5~2배속, BPM 기반 마디 타임라인, 음원 currentTime 기반 코드·가사 동시 강조, 가사 자동 스크롤, 카포 변경 시 실제 조성 유지 및 잡는 코드/운지표 자동 변경. 아리랑과 작은 별에 연습용 가사 타임라인 포함. 사용자 가사 입력, LRC 파일 가져오기/저장, 줄별 시간 입력/현재 재생 위치 캡처, 가사 전체 오프셋 지원. 음원을 별도로 연결해 연습 가능. 자동 가사 수집/음성 인식/유튜브 음원 동기화는 미지원. 파일 없는 수록곡은 무음 악보 가이드로 진행하며 원곡 녹음을 재생하지 않음.

`node test-timeline.cjs`로 카포 음높이 보존, 슬래시·단조·플랫 코드, 박자별 타임라인, 음원 종료 길이, 경계 탐색, LRC 파싱/오프셋/왕복 저장 검사.

`dist/`의 HTML/CSS/JS로 실행되는 한국어 기타 연습 웹앱. `node preview.cjs`로 로컬 실행.

구현: 전통곡 6곡의 자체 쉬운 편곡 검색, iTunes JSONP 일반 음원 검색, 유튜브 링크 검증·임베드·Chordify 외부 검색, 브라우저 음원 파일 분석, 조옮김/카포/운지표, 메트로놈, localStorage 저장, 인쇄.

제한: 유튜브 음원 추출 또는 서버 AI 채보는 구현하지 않음. 일반 음원 검색 결과에는 악보 미등록 표시. 파일 분석은 2초 간격 FFT/chroma와 major/minor 템플릿 기반 추정이며 정확한 채보를 보장하지 않음. 7th·sus·전위화음·비트/템포 추정은 미지원. 표시 BPM은 메트로놈 기본값. 저장 악보는 음원 파일을 포함하지 않음.

`node verify.cjs`로 합성 장·단조 화음, 무음, 조옮김, DOM 참조 검증. 외부 검색/영상/폰트는 각 제공자의 네트워크 연결 필요. 사용자 오디오 파일은 서버 전송하지 않음.
